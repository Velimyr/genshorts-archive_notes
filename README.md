# genshorts-archive_notes

Службова пам'ять пайплайна «Записки диванного архівіста» (https://t.me/archivist_notes).
Тут лише стан: історія ідей, черга, словник наголосів. Відео й матеріали лежать поза репозиторієм.

- `data/ideas.json` — усі ідеї (запропоновані, погоджені, відхилені, використані) зі статусами; з нього перевіряється, щоб теми не повторювалися.
- `data/stress_dict.json` — словник наголосів для озвучення: слово → форма, яку синтезатор вимовляє правильно.
- `data/telegram_state.json` — службовий стан бота (offset оновлень).

Секрети (токени) сюди НЕ комітяться.
